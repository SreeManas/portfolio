# Sree Manas Portfolio

A single-page digital engineering journal built with React, TypeScript,
Tailwind CSS, and Framer Motion.

The project direction lives in `PRODUCT_DIRECTION.md`. The implementation
foundation lives in `ARCHITECTURE.md`.

## Scripts

- `npm run dev` starts the local development server.
- `npm run build` type-checks and creates a production build.
- `npm run lint` runs static analysis.
- `npm run preview` serves the production build locally.
